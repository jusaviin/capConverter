FAQ

Can you provide an example calculation?

Certainly. The tool first calculates the average cap hit percentage for the duration of the original contract. It then calculates the amount of money the player would earn if the contract had started in the reference year assuming the player would earn the same average fraction of the cap hit throughout the contract period. 

Cap hit:                 5.0 M$
Number of seasons:       3
Contract start season:   2020-2021
Reference start season:  2025-2026

Cap ceilings for the relevant seasons:
2020-2021 = 81.5 M$
2021-2022 = 81.5 M$
2022-2023 = 82.5 M$
2025-2026 = 95.5 M$
2026-2027 = 104 M$
2027-2028 = 113.5 M$

The full calculation:
   (5 / 81.5) + (5 / 81.5) + (5 / 82.5) =
   (x / 95.5) + (x / 104) + (x / 113.5)
=> (x / 95.5) + (x / 104) + (x / 113.5) = 0.1833
=> (104 * 113.5 * x) / (95.5 * 104 * 113.5)
 + (95.5 * 113.5 * x) / (95.5 * 104 * 113.5)
 + (95.5 * 104 * x) / (95.5 * 104 * 113.5) = 0.1833
=> (104 * 113.5 * x) + (95.5 * 113.5 * x)
 + (95.5 * 104 * x) = (95.5 * 104 * 113.5) * 0.1833
=> 32575.250 x = 206636.93
=> x ~= 6.34 M$
Where do you find the salary cap information?

The historical salary cap information is available in Wikipedia. The NHL has announced the salary cap for the next couple of seasons. All the rest is a projection based on my best guess.

Where do you get the player contract details?

The contract data is provided by CapWages. I read all the contract data presented in this site from their API. If you want to get API access yourself, check their membership options.

How are future cap hits projected?

I have NHL confirmed data only until 2027-2028 season. After that, I am assuming 9% yearly increase in the salary cap. This is based on recent cap increases since the 2024-2025 season. The increases have been 8.52%, 8.90%, and 9.13% in each consecutive season since then. It seems reasonable to me to assume the salary cap continues to increase about 9% per season also in the future.

I want a different projection! How can I change this?

There is a gear icon to open settings in the top right corner of this page. This allows you to set your own percentage increase per season, or alternatively just edit the future cap hits by hand to whatever you want them to be!

What are the different modes?

In the cap converter mode, you are able to convert a contract from one season to another season keeping the average percentage taken from the salary cap the same.

In the contract list mode, you can list the players with the largest absolute cap hit, and largest percentage of the salary cap from the salary cap era.
